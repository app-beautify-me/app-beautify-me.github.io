# blog.beautify.me web site

- Build using [Jekyll](https://jekyllrb.com/docs/)
- Using teh [Minimal Mistakes Jekyll theme](https://github.com/mmistakes/minimal-mistakes)
- Hosted in [GitHub Pages](https://docs.github.com/en/pages)

Prerequisites:

```sh
# On fedora https://jekyllrb.com/docs/installation/other-linux/
$ sudo dnf install ruby ruby-devel openssl-devel redhat-rpm-config gcc-c++ @development-tools
$ gem install jekyll bundler

# Print installed versions
$ ruby -v
$ gem -v
$ gcc -v
$ g++ -v
$ make -v
```
